# NEJEN full package manifest: the maintainer's complete personal machine.
#
# This is NOT the base system. It is packages/core.txt (the NEJEN setup:
# boot/base + Hyprland shell) PLUS the maintainer's own applications:
# browsers, AI tools, office/media apps, docker, games, etc. It mirrors what
# is actually installed on the source machine, so dev-mode `install.sh`
# defaults to it (`--packages full`).
#
# The ISO and the distribution path use packages/core.txt ONLY.
#
# Superseded/duplicate packages removed:
#   gammastep   (hyprsunset kept instead: `nejen night toggle` is built
#                on `hyprctl hyprsunset` (deviation from the design doc)
#   bottom      (btop kept; the package was unused)
#   wofi        (walker is the launcher; waybar-countdown now uses walker)
#   wf-recorder (nejen screenrecord / gpu-screen-recorder)
#   sddm        (greetd + tuigreet)
#   yay         (paru)
