# NEJEN core package manifest: the distribution.
#
# This is what NEJEN *is*: boot/base system + the complete Hyprland desktop
# shell + the tooling the `nejen` command needs. Nothing else: no browsers, no AI tools, no office/media/consumer apps.
# Users install their own applications from the Arch repos and AUR afterwards.
#
# Consumed by:
#   install.sh --packages core   (dev-mode install of just the core setup set)
#   build-iso.sh / archiso       (the live ISO ships EXACTLY this plus the
#                                 releng live-boot infrastructure)
#
# The maintainer's full personal machine set lives in packages/full.txt
# (a superset of this file).
#
# Every entry below is either core desktop-shell function or was verified as
# referenced by shipped configs and scripts (grep before removing).
